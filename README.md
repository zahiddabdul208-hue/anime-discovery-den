# Anime Discovery Den

Build NIME, a premium anime discovery and streaming web application. Create a real working application, not just a static mockup.

DESIGN: Premium cinematic dark mode, near-black background, subtle purple accents, modern typography, large anime hero banner, polished poster cards, smooth hover effects, responsive desktop and mobile layouts. Use original branding and a professional streaming-platform layout.

BUILD THESE FEATURES:

1. Home page with featured anime, trending anime, popular titles, and genre sections.

2. Explore page with a functional search box and genre filters.

3. Anime detail page with poster, synopsis, genres, and episode list.

4. Watch page with a real HTML5 video player using a clearly identified authorized demo video. If no authorized episode video is configured, show a clear placeholder message instead of a fake play button.

5. Favorites list and watch history persisted in localStorage.

6. Real page navigation, working controls, loading and error states.

7. Use an available anime metadata API such as Jikan where appropriate, with error handling and clearly labeled fallback demo data.

8. Use reusable components, clean code, and accessible controls.

Do not scrape unauthorized anime streaming websites or invent streaming URLs. Do not add fake login, payment, or streaming features. Keep the first version simple and functional. Build the actual application, preview it, and fix errors you can detect. Explain how to publish the site and configure authorized video sources.
